# 冰城挑戰——活動時間線

樂善堂梁銶琚學校 2026–2027 四年級 STEAM DAY 當日流程。
日期是 2027年1月21日（星期四），時間以香港時間為準。

公開網址：https://clementwong116-lgtm.github.io/ice-city-timeline/

這是一個可安裝的網頁，給教師和學生在手機、平板和電腦查看。不需要帳號。第一次完整開啟並完成載入後，沒有網絡也可查看當日流程。

## 安裝到手機

請用上面的公開網址以 HTTPS 開啟。請先讓頁面完整載入一次。

### Android（Chrome）

1. 用 Chrome 開啟網址。
2. 若頁面出現「安裝到主畫面」，點按它。否則打開瀏覽器選單，選擇「安裝應用程式」或「加入主畫面」。
3. 之後從主畫面開啟。首次完整載入後，沒有網絡也可使用。

### iPhone／iPad（Safari）

1. 用 Safari 開啟網址。
2. 點底部分享按鈕。
3. 選擇「加入主畫面」。
4. 從主畫面開啟。首次完整載入後可離線使用。

## 部署

把這個資料夾的全部檔案放到任何靜態網站寄存，放在網站根目錄或子目錄都可以。頁面、清單和離線程式都使用相對路徑。手機要可靠地安裝和離線使用，網站必須是 HTTPS。
